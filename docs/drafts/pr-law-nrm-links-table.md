# Карта связей (Ф6): виды связи между положениями — на утверждение

Статус: **утверждено преподавателем как авторская учебная типология** (не общепринятая юридическая классификация). Демо-задание `DEMO-LAW-NRM-008` построено по этой таблице; тексты норм не сверены — задание остаётся демонстрационным.

**Решения преподавателя (5-й этап):**
- упорядоченное правило сохраняется для технической однозначности; ученику в условии объясняется, что типология авторская, а порядок — условие конкретного упражнения, а не универсальный принцип квалификации (поле `relationsNote`, обязательно при `ordered: true`);
- бланкетность отдельным восьмым видом не вводится;
- пара ст. 1064 — ст. 1067 ГК **убрана из автоматической проверки**; она переносится в задание с оценкой конкурирующих аргументов (VI-3, часть «Оценка доводов»): почему ст. 1067 можно интерпретировать как специальное регулирование и в каком смысле она допускает исключения;
- остальные пары утверждены предварительно — при условии сверки текстов и юридических интерпретаций.

## Как обеспечена взаимоисключаемость

Семь видов связи сами по себе **не образуют** строгой классификации по одному основанию: любое исключение — тоже специальная норма; определение понятия тоже уточняет другую норму; пара «правило — мера» может быть выражена через отсылку. Поэтому в задании действуют два механизма.

1. **Упорядоченное правило** (как для типов ошибок Т1–Т6): ученик проверяет виды по порядку и выбирает **первый подходящий**. Правило и определения показываются в условии; проверка данных требует, чтобы «связи нет» стоял последним.
2. **Разграничивающий признак** в определениях соседних видов, на которых чаще всего возникает конкуренция:
   - исключение — норма **сама** устанавливает последствие, противоположное общему правилу;
   - конкретизация — последствие общей нормы **сохраняется по общему правилу**, хотя может уточняться или допускать отступление по усмотрению правоприменителя.

Если для пары две квалификации остаются обоснованными **при заданных определениях**, пара в автоматическую проверку не берётся. Её можно оставить только с явно заданным подходом (как в V-2) или перенести в экспертную часть.

## Что было вынесено на решение (решено, см. выше)

1. Утвердить набор из семи видов и определения в формулировках из таблицы (или изменить их).
2. Утвердить упорядоченное правило как механизм однозначности.
3. Пара ст. 1064 — ст. 1067: оставить с определениями из таблицы (сейчас: конкретизация — 1 балл, исключение — 0 с объяснением границ интерпретации), **либо** убрать пару из автоматической проверки. Частичный балл (½) за «исключение» убран: при заданных определениях исключение не является «допустимым более слабым ответом», а противоречит определению.
4. Пара ПДД — КоАП: подтвердить, что бланкетный способ изложения не включается в список видов связи. Иначе пара станет неоднозначной, и её придётся заменить.
