# Практикум «Норма права»: реестр нормативных положений для официальной сверки

Основа будущего `SOURCES.md`. В публикуемый банк попадает задание, только если **все** положения, на которые оно опирается, имеют статус **A**.

**Статус на 11.10.2026: официальная сверка не проведена.** Сетевая политика окружения запрещает соединения с официальными источниками. Повторная проверка 11.10.2026 дала отказ для всех адресов:
- `pravo.gov.ru`, `publication.pravo.gov.ru` — официальный интернет-портал правовой информации;
- `consultant.ru`, `garant.ru` — СПС;
- `kremlin.ru`.

Текущие статусы B и C получены по вторичным источникам и выдаче поиска.

**Что записывается при сверке** — по каждому положению:

| Поле | Содержание |
|---|---|
| Акт | полное наименование, дата, номер |
| Структурная единица | статья, часть, пункт, абзац |
| Редакция | «ред. от ДД.ММ.ГГГГ» или «в ред. Федерального закона от … № …» |
| Источник | URL официального портала или СПС с датой редакции |
| Дата проверки | ДД.ММ.ГГГГ |
| Текст | дословно используемые фрагменты |
| Изменения, не вступившие в силу | есть / нет; если есть — дата вступления в силу |

**Уровни:**
- **A** — сверено с официальным источником;
- **B** — дословно совпадает в нескольких вторичных источниках;
- **C** — один источник или по памяти;
- **—** — материал ещё не выбран.

## 3. Порядок сверки, когда доступ появится

1. Для каждого положения открыть официальный текст в актуальной редакции на официальном портале правовой информации (действующие редакции кодексов — информационно-правовая система «Законодательство России» на `pravo.gov.ru`). Записать редакцию и дату проверки.
2. Проверить, нет ли **изменений, не вступивших в силу**. Если есть — записать дату вступления в силу и решить, использовать ли положение.
3. Сравнить дословно с текстом в задании; при расхождении — исправить задание и его объяснения.
4. Заполнить у задания `legal.act`, `legal.ref`, `legal.edition`, `legal.checked`, `legal.url`. Тест банка не пропустит задание без этих полей.
5. Обновить статус в этом реестре и перенести реестр в `docs/practicum/law-nrm/SOURCES.md`.
