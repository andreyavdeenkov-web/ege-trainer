## 4. Проверка «не угадывается по форме вариантов»

Автоматический тест (`tests/olymp-nrm-work.test.js`) проверяет каждое задание рабочего банка:
- **Длина.** В строках с авторскими формулировками (перечень вариантов встречается в банке один раз) правильный вариант не длиннее самого длинного неправильного более чем на 20 %. При проверке нашлись и исправлены 8 таких строк — например, слоты II-2 и V-2, связь пунктов в IV-1 и IV-2, системный вопрос в I-3.
- **Позиция.** В строках с авторскими формулировками варианты показываются в стабильном перемешанном порядке (`shuffle: true`). Порядок одинаков при каждом показе и после перезагрузки; номера вариантов в ответе не меняются. Канонические перечни («запрещающая / обязывающая / управомочивающая», «простая / сложная / альтернативная») остаются в привычном порядке: они одинаковы для многих строк и подсказкой не являются.
- **Двухвариантные строки** («верно / неверно», «материальная / процессуальная») есть только там, где решение содержательное. Их доля в баллах мала: III-2 — 3 из 12, I-1 часть Б — 5 из 15.

Содержательное действие по заданиям:
- I-1 — признак выбирается отдельно от вида;
- I-3 — доказательство из закона и системная связь;
- II-1 — нормативность при одинаковом виде документа (указ и указ, приказ и положение);
- II-2, V-2 — происхождение ошибки по проверке подстановкой;
- III-2 — разграничение двух оснований (средства и способ);
- IV-1, IV-2 — разграничение выраженного текста и реконструкции.

## 7. Как открыть рабочий банк самостоятельно

**Закрытый предпросмотр.** Страница доступна только владельцу. Она собрана командой `node scripts/bundle-preview.js <файл>` — это тот же код и те же задания, что в `olympiad-work.html`. Попытка хранится в вашем браузере; кнопка «Сбросить попытку рабочего банка» начинает заново.

**Локально:**
1. `git clone` репозитория, затем `git checkout claude/law-nrm-bank`.
2. В папке репозитория выполнить `node scripts/serve.js 8765` (нужен Node.js 18+).
3. Открыть в браузере `http://localhost:8765/olympiad-work.html#/pr/LAW/LAW-NRM` и нажать «Начать тренировку».

Основная страница `olympiad.html` рабочий банк не загружает; публикация на основном сайте не требуется.

## 8. Решения после проверки обязательной части (внесены)

- **I-1:** «этикет» в эпизоде 3 — ½; объяснение раскрывает пересечение категорий (по содержанию — этикет, по происхождению — обычай). Решающие признаки засчитываются, только если **все** выбранные признаки решающие: лишний признак «на всякий случай» делает ответ неверным. Вероятность угадать одной случайной отметкой — не выше 3 из 5, двумя — не выше 3 из 10 (закреплено тестом).
- **I-3:** критерий — определения из условия. В строке 4 вместо «не саморегулируемая» сказано, что закон не уполномочивает ассоциацию принимать обязательные акты; в объяснении: решает, придаёт ли закон обязательность актам организации, а не её организационно-правовая форма.
- **II-1:** «Не правовой акт» для информационного письма утверждён.
- **III-2:** «или договором» — прямое доказательство; «если иное не предусмотрено законом» — недостаточное доказательство договорной диспозитивности, но формулировка юридически верна (так и сказано в объяснениях).
- **IV-1, IV-2:** без изменений.
- **Мобильная разметка:** проверено на 390×844 и 360×640. Нажатие доходит до каждого фрагмента; исправление работает (ластик, смена метки другим инструментом, повторное нажатие тем же инструментом снимает метку). При переходе с клавиатуры фрагмент раньше мог оставаться под закреплённой панелью — теперь страница прокручивается. На невысоких экранах панель компактнее: 16 % высоты вместо 21 %.
