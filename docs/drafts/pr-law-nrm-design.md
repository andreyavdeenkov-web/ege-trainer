### 1.2. Чего нет (и что критично для этой темы)

1. **Развёрнутого ответа нет.** Ни одного поля для текста, который ученик пишет сам.
2. **Нет оформления нормативного текста.** Вопрос выводится через `textContent` одной строкой: нельзя показать статью закона отдельным блоком с реквизитами, абзацами и пунктами.
3. **Нет выделения фрагментов текста.** Гипотезу, диспозицию и санкцию сейчас можно только *выбрать из готовых вариантов*, а не найти в тексте.
4. **Нет многокритериальной карточки.** Классификацию по 8–9 основаниям можно собрать из `matching` (позиции — основания, варианты — значения), но у всех строк общий список вариантов: «императивная», «охранительная» и «общая» оказываются в одном списке, а «неприменимо» и «спорно» не выразить. Привязать вывод к словам нормы тоже нельзя.
5. **Нет частичного результата.** Вердикт бинарный: 8 из 9 верных оснований — это «Неверно». В `matching` подпись «Ошибок в позициях: 1 из 9» уже есть — этот приём можно переиспользовать.
6. **Нет общего текста для нескольких заданий.** Для олимпиадного вызова (три связанные статьи → шесть шагов анализа) нужно показывать одни и те же статьи в нескольких заданиях подряд.

Вывод: на существующих типах можно сделать разделы I, II и V в упрощённом виде (выбор + соответствие). Для двух главных разделов (III и IV) и для «Олимпиадного вызова» нужны новые компоненты, иначе ученик будет угадывать, а не анализировать.

## 2. Архитектура новых компонентов

Принцип: **только расширение.** Новые типы регистрируются через `OLY.types.register` и `OLY.ui.views.register`; ядро попытки, ключ хранилища, `LAW-CPT` и задания «Высшей пробы» не меняются. Старые попытки восстанавливаются как раньше (их типы не меняются).

### 2.0. Блок нормативного текста `legal` (общий для всех типов) — сложность **S**

Необязательное поле задания:

```js
legal: [{
  act: 'Гражданский кодекс РФ (часть первая)',
  ref: 'ст. 210',
  edition: 'ред. от …',          // редакция, по которой сверен текст
  checked: '2026-10-…',           // дата сверки
  text: [ 'Собственник несёт бремя содержания принадлежащего ему имущества, …' ]   // абзацы
}],
passage: 'NRM-VI-1'               // необязательно: общий текст для группы заданий
```

Отрисовывается над вариантами ответа как «цитата нормы» с реквизитами. Условные (вымышленные) нормы помечаются `fictional: true` и выводятся с подписью «Условная норма — не действующее законодательство». Абзацы вопроса (`question` с `\n`) — через `white-space: pre-line`.

### 2.1. Новый тип `analysis-grid` — «Карта анализа» — сложность **M** (≈2–3 дня с тестами и мобильной вёрсткой)

Универсальная таблица «строки × выбор», у каждой строки **свой** набор значений.

- В разделе III строки — **основания классификации**, значения — виды норм по этому основанию.
- В разделе I строки — **ситуации**, а в каждой строке два вопроса: «какой регулятор» и «решающий критерий разграничения». Так требование «объясните критерий» становится проверяемым.

```js
{
  type: 'analysis-grid',
  legal: [...],
  rows: [{
    id: 'method',
    label: 'Метод регулирования',
    options: ['Императивная', 'Диспозитивная', 'Рекомендательная', 'Критерий неприменим'],
    accept: [2],                      // верные значения; два и больше — спорная квалификация
    acceptNote: 'Принимается также …, если …',   // когда засчитывается альтернатива
    evidence: ['s3'],                 // фрагменты текста, подтверждающие вывод
    explanation: '…'
  }]
}
```

**Механика (компьютер и смартфон).**
1. Сверху — текст нормы, разбитый автором на фрагменты (фразы, оговорки, части предложения).
2. Ниже — основания списком-аккордеоном: «Основание 3 из 8». В строке — кнопки-значения, как в `matching`.
3. После выбора значения появляется шаг **«Подтвердите словами нормы»**: ученик нажимает фрагменты текста, на которых основан вывод (для ст. 210 ГК — «если иное не предусмотрено законом или договором»). Фрагменты подсвечиваются цветом строки.
4. Необязательное поле «Обоснование» (свободный текст): не проверяется автоматически, сохраняется в попытке и выводится в разборе рядом с эталоном.
5. Значения «Критерий неприменим» и «Спорная квалификация» — полноправные варианты, когда этого требует материал. Например, деление на управомочивающие, обязывающие и запрещающие не подходит к норме-дефиниции.

**Проверка.** Строка верна, если выбранное значение входит в `accept`, а отмеченные фрагменты пересекаются с `evidence`. Подпись: «Основания: 7 из 8 · доказательства: 6 из 8». Вердикт «Верно» — при полном совпадении, как в `matching`. В разборе у каждой строки показываются эталон, принятые альтернативы с условием и объяснение.

**Прогрессивное заполнение (вариант на согласование).** Режим `sequential: true`: следующее основание открывается только после выбора предыдущего. Для мобильной версии удобно, но в олимпиаде ученик сам решает, с чего начать. Рекомендую сделать режимом задания, а не поведением по умолчанию.

### 2.2. Новый тип `text-markup` — «Разметка нормы» — сложность **L** (≈3–4 дня)

Выделение гипотезы, диспозиции и санкции прямо в тексте.

```js
{
  type: 'text-markup',
  legal: [...],
  palette: [ { id: 'H', label: 'Гипотеза' }, { id: 'D', label: 'Диспозиция' }, { id: 'S', label: 'Санкция' } ],
  segments: [
    { id: 's1', text: 'В случае, если родители не предоставляют содержание своим несовершеннолетним детям,', key: 'H' },
    { id: 's2', text: 'средства … взыскиваются с родителей в судебном порядке.', key: 'S' },
    { id: 's3', text: ' — ', key: null, fixed: true }       // связка, не размечается
  ],
  lenient: ['s7'],                    // фрагменты со спорной границей — не влияют на оценку
  locate: [                           // «карта элементов»: где находится каждый элемент
    { element: 'S', options: ['В этом тексте', 'В другой статье этого акта', 'В другом акте', 'Не выражен и не требуется'],
      accept: [3], refAnswers: ['ст. 87 СК', '87'] }   // уточнение — краткий ответ
  ]
}
```

**Механика.**
1. Внизу экрана закреплена палитра «Г / Д / С / Стереть» (на смартфоне — sticky-панель, кнопки не меньше 44 px).
2. Ученик выбирает инструмент и нажимает фрагменты: они подчёркиваются цветом элемента (цвет + буква, чтобы не зависеть от цветовосприятия).
3. Для статьи с несколькими предписаниями палитра нумерованная: Г1, Д1, Г2, Д2… Первый шаг — «На сколько предписаний делится текст?»
4. Затем «Карта элементов»: для каждого элемента — «в этом тексте / в другой статье / в другом акте / не выражен и не требуется / реконструируется по смыслу» и при необходимости номер статьи.

**Почему фрагменты, а не произвольное выделение мышью.** Граница выделения на уровне слов на смартфоне неудобна и делает проверку произвольной («захватил ли ученик запятую»). Автор режет текст по юридически значимым границам: условие, правило, оговорка, мера. Ученик решает, *что* чем является, а не попадает пальцем в слово. Спорные границы помечаются `lenient`.

**Проверка.** Подпись «Фрагменты: 5 из 6 · карта элементов: 2 из 3». Разбор — переключатель «Мой разбор / Эталон» прямо на тексте и объяснение для каждого фрагмента.

### 2.3. Новый тип `open-response` — «Аргументированный ответ» — сложность **M** (≈1,5–2 дня)

Для разделов V и VI и для части заданий II: «найдите ошибку, объясните, исправьте, приведите контрпример».

- Структурированные поля, заданные в задании: «Ошибка», «Почему это ошибка», «Корректное рассуждение», «Контрпример».
- «Проверить» → ответ фиксируется, открываются **эталон** и **чек-лист критериев** (3–6 пунктов: «указал, что “обязан” описывает тип предписания, а не метод», «привёл норму с оговоркой “если иное не предусмотрено договором”»…).
- Ученик сам отмечает выполненные критерии (**самопроверка**). Обязательные критерии помечены.

**Решение, которое нужно от вас** (влияет на итоги и полосу номеров):

| Вариант | Как считается | Изменения |
|---|---|---|
| А (рекомендую) | Новый вердикт `self-checked`: в итогах отдельная строка «Самопроверка: 5 заданий, критериев выполнено 18 из 24». Самооценка не смешивается с автоматической проверкой | `attempt.summary`, `session.taskState`, полоса номеров, экран итогов, список допустимых вердиктов в `progress.js`; плюс тесты. Обратно совместимо |
| Б | Вердикт выводится из чек-листа: все обязательные критерии отмечены → «Верно» | Ядро не меняется, но «Верно» по самооценке выглядит так же, как автоматическое |

### 2.4. Выгрузка ответов для преподавателя — сложность **S**

Сервера нет. На экране итогов — кнопка «Скачать ответы для преподавателя»: файл с развёрнутыми ответами, разметкой, отмеченными доказательствами и самооценкой. Точка расширения `OLY.attemptStore.onCheck` уже есть: при появлении сервера сюда подключается отправка.

### 2.5. Что проверяется автоматически, а что нет

| Что делает ученик | Проверка |
|---|---|
| Выбор вида нормы, соответствие, «верно / неверно» | автоматически |
| Значение по каждому основанию классификации | автоматически, с принятыми альтернативами |
| Слова нормы, подтверждающие вывод | автоматически (пересечение с эталонными фрагментами) |
| Разметка Г/Д/С, «где находится элемент», номер статьи | автоматически |
| Письменное обоснование, исправленное рассуждение, контрпример, варианты толкования | самопроверка по эталону и чек-листу + выгрузка преподавателю |

Автоматическую проверку свободного текста по ключевым словам не предлагаю: олимпиадник быстро научится вставлять «слова-ключи», а именно это практикум и должен отучить делать.

### 2.7. Одна тема или две

Политика «одна попытка на тему» означает: если ученик завершит тему, не решив дополнительную часть, она закроется навсегда. Поэтому предлагаю **две темы** в разделе «Теория права»:

| Тема | ID | Заданий | Время |
|---|---|---|---|
| «Социальные нормы и норма права» — обязательная часть | `LAW-NRM` | 19 | 100–120 мин |
| «Норма права: олимпиадная лаборатория» — дополнительная часть | `LAW-NRX` | 14 | 130–150 мин (лучше в 2 подхода) |

Альтернатива: одна тема на 33 задания (возможно, потому что попытка сохраняется между сессиями), но тогда «Завершить» до конца дополнительной части закроет её.

## 3. Теоретическая рамка

### 3.1. Лекция № 7

**Текст лекции № 7 (Ростовцева, Литинский) мне не передан** — ни в сообщении, ни в репозитории. Поэтому набор оснований ниже собран по академической литературе (С. С. Алексеев, М. Н. Марченко, Н. И. Матузов и А. В. Малько, В. Н. Хропанюк, Ю. А. Денисов, А. Ф. Черданцев). Нужен файл лекции или перечень 8–9 оснований с занятия: тогда я сверю набор, терминологию и не повторю примеры и задания пособия.

### 3.2. Основания классификации, которые будут использоваться

| № | Основание | Значения | Статус |
|---|---|---|---|
| 1 | Предмет (отрасль) | конституционные, гражданские, уголовные… | общепринято |
| 2 | Роль в механизме регулирования | материальные / процессуальные | общепринято |
| 3 | Метод (способ регулирования) | императивные / диспозитивные; отдельно — рекомендательные, поощрительные | общепринято; «полуимперативные» (норма-минимум в трудовом праве) — дискуссионный тип, засчитывается с обоснованием |
| 4 | Характер предписания | управомочивающие / обязывающие / запрещающие | общепринято; к нормам-дефинициям и нормам-принципам может быть неприменимо |
| 5 | Функция | регулятивные / охранительные | общепринято |
| 6 | Объём (сфера) действия | общие / специальные / исключительные (Алексеев) | общепринято; «общая — специальная» относительно: только в паре с конкретной нормой |
| 7 | Степень определённости | абсолютно определённые / относительно определённые / альтернативные; у санкций то же | общепринято |
| 8 | Специализированные нормы | дефиниции, принципы, декларации, отсылочные, коллизионные, оперативные | дискуссионно: являются ли они нормами в полном смысле |
| 9 | Субъект правотворчества и юридическая сила, круг лиц, время, территория | закон / подзаконный акт; федеральные, региональные, локальные; постоянные и временные | общепринято; применяется выборочно, по материалу |

Отдельно разводятся **способ изложения** нормы в статье (прямой, отсылочный, бланкетный) и **классификация самой нормы**: это разные основания, и смешивать их — типичная олимпиадная ошибка.

### 3.3. Структура нормы: позиции, которые закладываются в ответы

- **Норма права ≠ статья ≠ нормативное предписание.** Статья — единица текста акта; предписание — минимальная мысль-веление, выраженная в тексте (С. С. Алексеев); норма как логическая модель «если — то — иначе» часто собирается из нескольких статей и даже актов.
- **Трёхэлементная модель — логическая реконструкция**, а не требование к каждой статье. Альтернативы: двухэлементный взгляд (регулятивная норма = гипотеза + диспозиция, охранительная = гипотеза + санкция; связь между ними — «норма-пара») и понимание санкции как элемента охранительной нормы, а не каждой нормы.
- **Уголовно-правовая «диспозиция» ≠ диспозиция в ТГП.** В ст. 105 УК описание деяния — это гипотеза охранительной нормы; запрет убивать, то есть регулятивная диспозиция, в тексте только подразумевается.
- **Санкция ≠ наказание.** Взыскание алиментов в судебном порядке и недействительность сделки — правовосстановительные меры, но тоже санкции в теоретическом смысле.

Каждый спорный пункт в ответах получает формулу: «засчитывается вариант X при обосновании Y; вариант Z — при ссылке на позицию автора W».

## 5. Четыре показательных задания

### Пример 1. III-3 — ГПК РФ, ст. 39 ч. 1 (карта анализа)

> *Рабочий текст, сверить:* «Истец вправе изменить основание или предмет иска, увеличить или уменьшить размер исковых требований либо отказаться от иска, ответчик вправе признать иск, стороны могут окончить дело мировым соглашением…»

Основания: отрасль · материальная / процессуальная · метод · характер предписания · функция · объём действия · степень определённости · адресат.

Ловушка — **метод**. Ученик видит «вправе», вспоминает «принцип диспозитивности» гражданского процесса и ставит «диспозитивная». Но диспозитивность *метода* означает, что субъекты могут своим соглашением установить иное правило, чем в норме. Здесь этого нет: стороны не могут договориться, что истец лишается права отказаться от иска. Норма **управомочивающая и императивная**, а закрепляет она **принцип** процессуальной диспозитивности. Доказательство — фрагмент «вправе» для основания «характер предписания» и *отсутствие* оговорки «если иное не предусмотрено договором» для основания «метод». Пустая отметка тоже доказательство: ученик отмечает, что такой оговорки нет.

**Ценность:** разводит три созвучных понятия (управомочивающая норма, диспозитивная норма, принцип диспозитивности), которые олимпиадники путают систематически. Механика доказательства не даёт угадать: нужно показать, *на чём* основан вывод.

### Пример 2. IV-3 — Конституция, ст. 38 ч. 3 → СК, ст. 87 (разметка + карта элементов)

> *Рабочий текст, сверить:* ч. 3 ст. 38 Конституции: «Трудоспособные дети, достигшие 18 лет, должны заботиться о нетрудоспособных родителях».

Ученик размечает: «трудоспособные дети, достигшие 18 лет» и «о нетрудоспособных родителях» — гипотеза (условия: возраст, трудоспособность, нетрудоспособность родителей); «должны заботиться» — диспозиция. В карте элементов для санкции выбирает «в другом акте» и указывает ст. 87 СК (взыскание алиментов в судебном порядке).

Вторая часть задания — короткий аргументированный ответ: «Является ли взыскание алиментов санкцией, если это не наказание?» Ожидаемый ответ: да, в теоретическом смысле это правовосстановительная санкция (принудительное исполнение неисполненной обязанности); наказанием она не является.

**Ценность:** три навыка сразу — неявная структура конституционной нормы, поиск санкции по системе законодательства, различение санкции и наказания. Ошибка «санкции нет, значит, норма декларативная» здесь показательна.

### Пример 3. V-2 — «Диспозиция ст. 105 УК» (найдите ошибку юриста)

> Студент: «В ч. 1 ст. 105 УК диспозиция — “Убийство, то есть умышленное причинение смерти другому человеку”, а санкция — “наказывается лишением свободы…”. Значит, гипотезы в этой норме нет: норма двухэлементная».

Поля ответа: ошибка · почему · корректное рассуждение · контрпример или дополнительная норма.

Ошибка не в двух элементах (двухэлементный взгляд на охранительную норму допустим), а в **переносе уголовно-правового термина в ТГП**. В уголовном праве «диспозицией» называют описание состава преступления. В терминах теории государства и права это гипотеза охранительной нормы («если лицо умышленно причинит смерть другому человеку…»), её условия дополняются Общей частью (возраст — ст. 20, вменяемость — ст. 21). Регулятивная диспозиция — запрет убивать — выводится из охранительной нормы и из ст. 20 Конституции. Чек-лист: 1) назван терминологический сдвиг; 2) указано, что описание деяния — гипотеза; 3) названа подразумеваемая регулятивная норма; 4) упомянута Общая часть; 5) не утверждается, что «санкции нет».

**Ценность:** самая показательная ошибка темы. Она бьёт по ученику, который хорошо учил УК, но не понимает, что ТГП и отраслевая наука используют одно слово в разных значениях.

### Пример 4. VI-3 — ГК 1064 → ГК 1066 → УК 37 (олимпиадный вызов)

Шаги:
1. Разделите ст. 1064 на нормативные предписания (разметка с нумерованной палитрой).
2. Классифицируйте ст. 1066 по объёму действия (*исключительная* по отношению к п. 1 ст. 1064) и по функции. Принимается: охранительная (часть охранительного механизма деликтной ответственности) и «специализированная норма-исключение» — при обосновании.
3. Где гипотеза ст. 1066? В тексте: «вред, причинённый в состоянии необходимой обороны, если при этом не были превышены её пределы». Понятие обороны и её пределы в ГК не определены — ученик должен найти их в ч. 1–2 ст. 37 УК.
4. Развёрнутый ответ: можно ли применять ст. 37 УК для толкования гражданско-правовой нормы? Допустимые позиции: межотраслевое (системное) толкование единого понятия — да; осторожность из-за различия целей отраслей — тоже допустимо, при обосновании. Не засчитывается: «ст. 37 — уголовная, поэтому в гражданском деле не применяется» без аргументов.
5. Студенческая ошибка из V-4 (коллизия и «более поздняя норма») здесь не повторяется: проверяется не разграничение коллизии и исключения, а **построение нормы из трёх актов**.

**Ценность:** настоящее юридическое мышление — норма собирается из разных отраслей, одно понятие работает в двух кодексах, и у вопроса есть несколько защищаемых ответов с явными критериями.

## 6. Контроль качества (план Этапа 3)

1. Каждая реальная норма — реквизиты, редакция, дата сверки в `SOURCES.md` и в поле `legal.edition`.
2. Нормы, которые не удалось сверить с официальным текстом, не используются как цитаты, либо выводятся с пометкой «текст не подтверждён».
3. Каждое спорное основание — альтернативы и условия в `acceptNote`.
4. Тесты банка: ключи, `evidence` ссылается на существующие фрагменты, у строк с `accept.length > 1` есть `acceptNote`, у `open-response` — чек-лист и эталон, распределение уровней и `order`.
5. Хронометраж: прохождение обязательной части по таймеру на смартфоне.
6. Сверка с лекцией № 7 и пособием Литинского на отсутствие совпадений (после получения файла).

## 7. Источники и ограничения проверки

- В этой среде **нет прямого доступа** к КонсультантПлюс, Гаранту и pravo.gov.ru (соединение запрещено сетевой политикой). Доступен только веб-поиск со сниппетами.
