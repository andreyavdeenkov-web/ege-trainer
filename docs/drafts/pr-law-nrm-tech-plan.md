## 0. Главное ограничение: не нарушить `LAW-CPT`

| Что | Гарантия |

| Политика попыток трека `PR` (`practicum.js`) | **не меняется**: новые темы наследуют одну попытку и сохранение |
| Ключ хранилища `olymp-trainer:attempts:v1`, формат снимка попытки | **не меняются**; новые поля — только внутри ответов и результатов новых типов |
| Существующие типы `single-select`, `multiple-select`, `matching` | логика проверки не меняется; у `matching` — только необязательные поля (объяснение неверного варианта, ½ балла за допустимую роль) |
| Вердикты существующих заданий | остаются `correct` / `incorrect` / `unanswered`; новый `partial` выдают только новые типы |
| «Высшая проба», тренажёр ЕГЭ | не затрагиваются |

**Защитные тесты — первый коммит, до любых изменений:**

1. **Снимок `LAW-CPT`:** 24 задания, порядок `order`, типы, ключи, число вариантов — сравнение с зафиксированным эталоном.
2. **Восстановление попытки:** фикстура сохранённой попытки `PR/LAW/LAW-CPT` (начатой и завершённой) восстанавливается без потерь после всех изменений.
3. **Вердикты:** проверка всех заданий `LAW-CPT` по ключу даёт только `correct` / `incorrect`; итоги без баллов (`scoring: null`) — как сейчас.
4. **Порядок скриптов** `olympiad.html` и наличие всех файлов данных — существующий тест расширяется на новые файлы.

Эти тесты запускаются после каждого шага. Красный тест останавливает работу.

## 3. Составное задание: формат данных (кратко)

```js
{
  id: 'PR-LAW-NRM-006', type: 'compound', order: 6, level: 3, block: 'classification',
  legal: [{ act: 'ГПК РФ', ref: 'ст. 39 ч. 1', edition: 'ред. от …', checked: '2026-…', url: '…',
            fragments: [{ id: 'f1', text: 'Истец' }, …] }],
  references: [ /* справочные нормы в том же формате */ ],
  parts: [
    { id: 'A', type: 'analysis-grid', component: 'K', rows: [ { id: '4b', label: '…',
        options: ['Императивная', 'Диспозитивная', 'Поощрительная'], key: 0,
        wrong: { 1: 'Вы применили определение лекции…', 2: '…' },
        evidence: { key: ['r1', 'r2'], max: 3, component: 'T' } } ] },
    { id: 'C', type: 'analysis-grid', component: 'R', rows: [ /* доводы */ ] }
  ],
  scoring: { maxPoints: 18, rule: 'components', basis: 'author' },
  explanation: '…', typicalMistake: '…', hintGuard: ['…']
}
```

Ответ ученика — объект `{ A: …, C: … }`. Он проверяется `cleanResponse` составного типа, поэтому восстановление попытки после перезагрузки работает тем же механизмом, что и у существующих типов.

## 4. Тесты банка нового практикума

**Структура и учебные поля:**
- `order`, `level`, `block`, `tags`, `explanation` у каждого задания;
- уникальность ID и `order` в теме.

**Обратная связь:**
- у каждого неверного варианта каждой строки, слота и роли есть объяснение;
- у типов ошибок — объяснение для соседнего по порядку типа.

**Баллы:**
- `maxPoints` равен сумме баллов частей.

**Однозначность:**
- нет условных альтернатив;
- равноправные альтернативы указаны явно;
- «спорно» — только с осью спора в ключе.

**Качество** (спецификация, § 3.5):
- доля «верно» в доводах и утверждениях — 35–65 %;
- длина правильного варианта не выделяется;
- не менее трети пар «по двум определениям» дают одинаковый ответ;
- у слотов нет общих списков вариантов;
- в задании не больше 5 бинарных строк.

**Перекрёстные подсказки:**
- пара «статья + вопрос» не повторяется в разных темах;
- фразы из `hintGuard` не встречаются в объяснениях предшествующих заданий.

**Сверка:**
- у каждого `legal` и `references` заполнены `edition`, `checked`, `url`;
- задание без них не загружается.
