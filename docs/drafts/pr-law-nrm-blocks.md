# Дополнительные блоки практикума «Норма права»: состояние внедрения

Версия 1 · 11.10.2026 · ветка `claude/law-nrm-bank` · страница `olympiad-work.html` (не публикуется).

**Размещение (решение преподавателя).** Каждый блок — отдельная тема каталога со своей оцениваемой попыткой: `LAW-NRA` (А), `LAW-NRB` (Б), `LAW-NRC` (В), `LAW-NRD` (Г). Записи тем добавлены в `data/olympiads/subjects/social.js` рядом с `LAW-NRM`. Пока у тем нет опубликованных заданий трека PR, ученик их не видит: на основной странице заданий этих тем нет, это проверяет тест. Данные блоков — в `work/law-nrm/block-*.js` и подключаются только к рабочей странице.

**Общие правила для всех блоков:**
- автоматическая проверка;
- одна оцениваемая попытка (политика трека PR), после неё — разбор без повторного оценивания;
- у каждого неверного варианта — краткая причина и подробное объяснение;
- спорные квалификации — только с подходом, заданным в условии, и с границами интерпретации в разборе;
- форма вариантов не подсказывает ответ (тест длины и перемешанный показ);
- все нормативные тексты — `verified: false`, задания — `draft: true`, статус `unconfirmed` или `no-legal-text`;
- учебные документы условия помечены `fictional: true` и официальной сверке не подлежат.

## Блок Б — «Лаборатория классификации» (`LAW-NRB`) — внедрён

Определения по объёму согласованы с утверждённой типологией связей: **исключительная** норма сама устанавливает противоположное последствие; **специальная** сохраняет последствие общей нормы, уточняя условия или допуская отступление по усмотрению правоприменителя.

**Отступления от реестра — нужно ваше подтверждение:**
- **III-6, ключ ч. 2 по объёму.** Реестр планировал ключ «исключительная». По утверждённым определениям (таблица видов связи, решение 5-го этапа) освобождение по усмотрению правоприменителя («может быть освобождено» комиссией) — признак специальной нормы. Ключ сделан «специальная», чтобы классификация в блоке Б не расходилась с типологией связей. Контраст с исключительной нормой показан двумя способами: гипотетической редакцией «не подлежит ответственности» (строка Б3) и ст. 1066 ГК в III-7, где норма сама устанавливает противоположное последствие.
- **III-7, отбор оснований.** Отбор 4–6 из 11 оснований (образец 4) реализован как квалификация по четырём основаниям. В одном из них есть вариант «неприменимо или тривиально» — это то же решение, что в III-3. Механики свободного отбора из 11 оснований в типах нет. Баллы: 13 вместо 15 по образцу.
- **III-4.** Основание «по объёму» не используется. Соотношение ст. 92 со ст. 91 — сокращённое время вместо нормального — нельзя однозначно квалифицировать ни как сохранение последствия, ни как противоположное последствие.
