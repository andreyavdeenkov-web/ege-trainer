## 1. Как читать реестр

**Навыки (спецификация § 1):**
- Н1 — признаки нормы права в правовых ситуациях и пределы действия нормы (в том числе локальной);
- Н2 — признаки нормы права;
- Н3 — квалификация по основанию;
- Н4 — применимость основания;
- Н5 — текстовое доказательство;
- Н6 — реконструкция структуры;
- Н7 — системный поиск;
- Н8 — диагностика ошибок;
- Н9 — работа с научным спором.

**Форматы:**
- Ф1 — классификационная карта;
- Ф2 — разметка;
- Ф3 — краткий ответ;
- Ф4 — систематизация;
- Ф5 — поиск ошибки;
- Ф6 — карта связей;
- Ф7 — оценка доводов;
- Ф8 — конструктор;
- Ф9 — множественный выбор;
- составное задание — по механизму последовательной фиксации частей.

**Уровни:** 1 — базовый, 2 — применение, 3 — олимпиадный.

**Время.** «План» — по спецификации. «Расчёт» — по `scripts/estimate-time.js` для заданий, у которых есть демо, иначе оценка по числу решений по той же модели:
- чтение — 110 слов/мин;
- выбор — 20 с;
- доказательство — +35 с;
- метка — 6 с;
- ошибочный шаг — +40 с;
- довод — 40 с;
- краткий ответ — 45 с.

**Статус ключа:**
- **образец** — утверждённый образец;
- **демо** — реализован и проверен тестами на демо-данных;
- **план** — предварительный ключ по спецификации, требует экспертизы до программирования.

**Статус источника** (по реестру источников): A — сверено; B — совпадает в нескольких вторичных источниках; C — один источник или по памяти; «—» — материал не выбран. **Редакция:** «не установлена» — до официальной сверки.
