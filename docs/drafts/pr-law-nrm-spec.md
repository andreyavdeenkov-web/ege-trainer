## 1. Цель и проверяемые навыки

Цель — научить школьника проводить юридический анализ нормы. Каждый шаг анализа превращён в решение, которое программа проверяет однозначно.

| Код | Навык | Каким действием проверяется автоматически |
|---|---|---|
| Н1 | Различение социальных регуляторов | вид нормы + решающий признак разграничения |
| Н2 | Признаки нормы права | отнесение положения к нормам права / индивидуальным предписаниям / корпоративным правилам |
| Н3 | Квалификация по основанию | значение по основанию |
| Н4 | Применимость основания | «содержательно / тривиально / неприменимо / спорно» + указание, между чем спор |
| Н5 | Текстовое доказательство | отметка фрагментов нормы, на которых держится вывод |
| Н6 | Реконструкция структуры | разметка Г / Д / С; неразмеченный отсутствующий элемент |
| Н7 | Системный поиск | место недостающего элемента; номер статьи |
| Н8 | Диагностика ошибок | ошибочные шаги, тип ошибки, сборка корректного утверждения |
| Н9 | Работа с научным спором | квалификация **в каждом из названных подходов**, отнесение доводов к позициям |

## 2. Теоретическая рамка

### 2.1. Основания — по лекции № 7

| № | Основание (термин лекции) | Виды |
|---|---|---|
| 1 | По предмету регулирования | конституционно-правовые, гражданско-правовые, уголовно-правовые и др. |
| 2 | По характеру регулируемых отношений | материальные / процессуальные |
| 3 | По способу установления правил поведения | императивные / диспозитивные / поощрительные |
| 4 | По средствам регулирования | запрещающие / обязывающие / управомочивающие |
| 5 | По выполняемым функциям | регулятивные / охранительные |
| 6 | По времени действия | временные / постоянные |
| 7 | По кругу лиц | общие / специальные |
| 8 | По сфере действия | федеральные / региональные / локальные |
| 9 | По роли в правовой системе | учредительные, декларативные, дефинитивные, коллизионные, оперативные, «каучуковые» |

**Расширения** — значок «дополнение к лекции»:
- **Р1.** По объёму регулирования: общие / специальные / исключительные (С. С. Алексеев).
- **Р2.** Рекомендательные нормы в основании № 3.

**Структура** — по § 7.5–7.6 лекции: виды гипотез, диспозиций и санкций; способы изложения; определённость диспозиции и санкции.

### 2.2. Норма, статья, нормативное предписание

Каждое задание явно указывает, **что** анализируется: часть статьи, отдельное предписание или норма, реконструированная из нескольких положений.

### 2.3. Спорные вопросы: как сделать проверку однозначной

**Правило.** Если правильность ответа зависит от выбора научного подхода, задание само **называет подход или определение**, либо просит ответить **в каждом из подходов отдельно**. Если правильность зависит от аргументации, которую нельзя свести к однозначным решениям, этот элемент **откладывается** (§ 7).

| № | Спорный вопрос | Как устроена автоматическая проверка |
|---|---|---|
| С1 | Определение диспозитивной нормы: в лекции широкое («позволяют определять вариант поведения»), в литературе узкое («применяется, если стороны соглашением не установили иное») | две строки карты: «по определению лекции» и «по определению “если стороны не установили иное”». В каждой один правильный ответ |
| С2 | «Общие / специальные»: по кругу лиц (№ 7) и по объёму регулирования (Р1) | два основания с разными названиями; смешение — ошибка с отдельным объяснением |
| С3 | Структура нормы в статье Особенной части УК: (а) «охранительная норма» (описание деяния — гипотеза), (б) «единая норма-запрет» (описание — диспозиция) | подход указывается в условии разметки или оценка даётся по каждому подходу отдельно; автоматически оцениваются только утверждения, верные или ошибочные при любом подходе |
| С4 | Санкция в широком смысле (по лекции, включая правовосстановительную) и в узком (мера ответственности) | в условии указано, в каком смысле понимается санкция, либо утверждения оцениваются отдельно для каждого смысла |
| С5 | Трёхэлементная модель vs «норма-пара» | модель названа в условии |
| С6 | «Каучуковые» нормы: вид нормы или свойство формулировки | ученик не решает, кто прав, а относит доводы к позициям |
| С7 | Отсылочная и бланкетная — по лекции или по Алексееву / Марченко | в условии — определение лекции; академическое различение — в объяснении |
| С8 | Позитивные санкции | в условии — классификация лекции |
| С9 | Относительная определённость | в условии — определение лекции; задания не смешивают её с диспозитивностью |
| С10 | Адресат нормы — в гипотезе или в диспозиции | **равноправные ответы**: оба засчитываются автоматически, это спорная граница фрагмента |

**Варианты «спорно».** Вариант «спорно» есть только там, где спор признан в ключе. Выбрав его, ученик указывает, **между какими квалификациями** спор (выбор двух значений). Это проверяется автоматически.

**Равноправные альтернативы** допускаются, если ответ верен независимо от рассуждения: спорная граница фрагмента, разные формы записи номера статьи. Альтернатив, которые верны «только при обосновании», в банке нет.

## 3. Форматы заданий

### 3.1. Сводка

| Код | Формат | Что делает ученик | Что проверяет программа | Почему не угадывание |
|---|---|---|---|---|
| **Ф1** | **Классификационная карта** | квалифицирует по основаниям; решает, применимо ли основание; отмечает доказательства | значение по каждой строке; решение о применимости; ось спора; пересечение отмеченных фрагментов с ключом | 6–10 независимых решений, у части строк 4–7 значений, плюс доказательство |
| **Ф2** | **Разметка нормы** | помечает фрагменты текста; указывает, где находится недостающий элемент; характеризует элементы по видам лекции | метку каждого фрагмента; строки карты элементов; вид гипотезы, санкции, способ изложения | вариантов нет — только текст; отсутствующий элемент нужно не отметить |
| **Ф3** | **Краткий самостоятельный ответ** | вводит номер статьи, число, термин | совпадение после нормализации (§ 3.3) | пустое поле; ответы закрытые и однозначные |
| **Ф4** | **Систематизация** | распределяет фрагменты нескольких актов по ролям в норме | роль каждого фрагмента | вариантов больше, чем позиций; роли повторяются; есть «не относится» |
| **Ф5** | **Поиск ошибки** | отмечает ошибочные шаги; определяет тип каждой ошибки; собирает корректное утверждение | отмеченные шаги; тип ошибки по шагу; выбор в каждом слоте конструктора | верные шаги — ловушки; типов ошибок 6; слоты независимы |
| **Ф6** | **Карта связей** | для пар положений из разных актов определяет вид связи | вид связи для каждой пары | 7 видов связи, включая «связи нет» |
| **Ф7** | **Оценка доводов** | для каждого довода решает: верный и подтверждает вывод / верный, но к выводу не относится / неверный; в споре — к какой позиции относится довод | решение по каждому доводу | каждый довод — самостоятельный анализ; три исхода на строку |
| **Ф8** | **Конструктор формулировки** | заполняет пропуски в юридическом утверждении (каждый слот — 3–5 вариантов) | вариант в каждом слоте | слоты независимы: 3 слота по 4 варианта — 1,6 % на угадывание |
| Ф9 | Множественный выбор (не более одного задания) | оценивает каждое из 6 положений | совпадение по каждому положению | каждое положение — отдельный кейс |
| — | ~~Один ответ из четырёх~~ | — | не используется | — |

Задание обычно сочетает два-три формата. Ф7 и Ф8 заменяют прежнюю письменную аргументацию: проверяется **логика рассуждения**, а не умение её изложить.

### 3.2. Классификационная карта

- **Опорные основания** (4–6) выбирает автор. Все девять оснований механически не заполняются.
- **Проверка применимости** (2–3 строки): содержательно → вид; тривиально; неприменимо; спорно → между какими значениями.
- **Отбор оснований** (уровень 3): ученик выбирает 4–6 из 11.
  - **ключевые** основания — баллы за выбор и за квалификацию;
  - **неприменимые** — их выбор — ошибка;
  - **допустимые** — проверяются и комментируются, в баллы не входят.
- **Доказательство**: 1–3 фрагмента нормы или справочных норм. Отсутствие оговорки само по себе доказательством не служит — нужен положительный фрагмент.
- **Строки по подходам** (С1, С4): одна квалификация — в двух строках, для двух названных определений.

### 3.3. Краткий ответ: нормализация

Свободные формулировки не вводятся. Если нужно «выписать условие из закона», ученик **отмечает фрагмент в тексте** (это Ф2 или доказательство Ф1).

| Тип ответа | Что принимается |
|---|---|
| Ссылка на статью | номер (в том числе вида «12.6») + необязательные часть / пункт + кодекс по списку синонимов («ГК», «ГК РФ», «Гражданский кодекс»). «ст. 1064», «1064 ГК», «статья 1064 ГК РФ» равнозначны. Неверный кодекс — ошибка с объяснением |
| Число | целое; слова «два», «2» равнозначны |
| Термин | закрытый список форм, заданный автором; без учёта регистра и ё |

## 4. Модель оценивания

### 4.1. Компоненты

Все три компонента проверяются автоматически.

| Компонент | Что входит |
|---|---|
| **К — квалификация** | значения по основаниям, применимость, роли фрагментов, место элемента, виды элементов, краткие ответы, вид связи |
| **Т — текстовое доказательство** | отмеченные фрагменты; разметка Г / Д / С |
| **Р — логика рассуждения** | ошибочные шаги и их типы, оценка доводов, слоты конструктора, квалификация по подходам |

### 4.2. Статусы элемента

| Статус | Когда | Балл |
|---|---|---|
| ✓ верно | совпадает с ключом или с равноправной альтернативой | полный |
| ½ частично | допустимый, но более слабый ответ; его правильность не зависит от рассуждения | 0,5 |
| ✗ неверно | ответ вне ключа | 0 |

### 4.3. Начисление баллов

| Формат | Правило |
|---|---|
| Ф1, строка | К: 1 (или ½). Т: 1 — отмечен хотя бы один ключевой фрагмент и не больше одного постороннего |
| Ф1, применимость | 1 — верное решение. «Спорно»: 1 — если указаны обе спорящие квалификации, ½ — если указана одна |
| Ф1, отбор | 1 за каждое выбранное ключевое основание; 1 — не выбрано ни одного неприменимого |
| Ф2 | Т: по 1 за каждый полностью размеченный элемент; спорные фрагменты не влияют; 1 — отсутствующий элемент не размечен. К: по 1 за строку карты элементов и характеристики |
| Ф3 | 1 — ответ совпал после нормализации |
| Ф4, Ф6 | 1 за позицию или пару (½ — допустимая более слабая роль) |
| Ф5 | 2 — первый ошибочный шаг (если «первый» однозначен); 1 — каждый следующий; 1 — не отмечен ни один верный шаг; по 1 — тип ошибки каждого ошибочного шага; по 1 — каждый слот конструктора |
| Ф7, Ф8 | 1 за каждый довод или слот |
| Ф9 | 1 за каждое правильно оценённое положение |

Отрицательных баллов нет. Ограничение «не больше трёх фрагментов на строку» и балл за «не отмечен ни один верный шаг» не позволяют отмечать всё подряд.

### 4.4. Вердикт задания

| Вердикт | Условие | Полоса номеров |
|---|---|---|
| **Верно** | получены все баллы | зелёный |
| **Частично** | получена часть | жёлтый |
| **Неверно** | 0 баллов | красный |

Баллы — авторские (`scoring.basis: 'author'`). Сумма по теме показывается **одним числом**, поскольку все баллы проверены одинаково.

### 4.5. Обратная связь

После «Проверить» ученик видит:

1. **По каждому элементу** — статус, правильный ответ и объяснение.
2. **Объяснение конкретной ошибки.** Для каждого неверного варианта каждой строки в данных есть своё объяснение: почему именно этот выбор неверен. Пример: ответ «диспозитивная» по академическому определению → «Вы применили определение лекции. По определению “если стороны не установили иное” вопрос другой: могут ли стороны соглашением отменить эти права?» Тест банка требует объяснение для каждого неверного варианта.
3. **Типичная ошибка задания** — если есть ошибки.
4. **Общий разбор.**
5. В режиме просмотра — переключатель **«Мой ответ / Эталон»** прямо на тексте нормы.

**В задании:**

> **Частично** — 14 из 17
> Квалификация 8 / 9 · Доказательство 3 / 3 · Логика рассуждения 3 / 5

**В итогах темы:**

> **52 из 61 балла** · квалификация 30 / 34 · доказательство 12 / 13 · логика 10 / 14
> верно 6 · частично 5 · неверно 0

Процент не показывается, как в `LAW-CPT`.

## 5. Попытки и повторное изучение

- **Одна оцениваемая попытка на тему** — действующая политика трека `PR` (`allowRetake: false`, `allowRetryMistakes: false`, `allowRetrySkipped: false`, `persistAttempts: true`). Новые темы её наследуют. `LAW-CPT` и политика не меняются.
- **Во время попытки** ответ после «Проверить» становится только для чтения. Сразу показываются статусы, правильные ответы и объяснения.
- **После завершения** тема открыта для просмотра: свои ответы, разметка, отмеченные доказательства, баллы по компонентам, эталоны, объяснения ошибок. Фильтр «все / с ошибками / частично». Результат не меняется.
- **Повторного прохождения нет.**
- **В перспективе** — тренировка на новых нормах (те же навыки Н1–Н9 на другом материале); не сейчас.

## 6. Структура банка

**31 задание:**
- **обязательная часть** — 11 заданий, ≈84 мин;
- **4 дополнительных олимпиадных блока** — 20 заданий, ≈190 мин.

Каждый блок — отдельная тема каталога со своей попыткой. Все 31 задание переработаны под автоматическую проверку; полностью отложенных заданий нет. Отложены отдельные **элементы** (§ 7).

Уровни: 1 — базовый, 2 — применение, 3 — олимпиадный. ★ — образцы.

### 6.1. Обязательная часть — «Социальные нормы и норма права» (`LAW-NRM`)

| № | Задание | Форматы | Ур. | Мин |
|---|---|---|---|---|
| I-1 ★ | Шахматный турнир: пять эпизодов — вид нормы, решающий признак; что меняется, когда этикет становится корпоративной нормой | Ф1 | 1 | 7 |
| I-3 | Устав клуба, правила внутреннего трудового распорядка, правила для обучающихся, этический кодекс: локальная правовая или корпоративная норма + доказательство из закона | Ф1 | 2 | 7 |
| II-1 | Нормативное или индивидуальное предписание; постановление Пленума — «спорно» с указанием спора | Ф1 | 1 | 5 |
