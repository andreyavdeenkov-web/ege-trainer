# ЕГЭ Обществознание — тренажёр

Веб-приложение для подготовки к ЕГЭ по обществознанию. Первая версия — тренажёр заданий с множественным выбором: ученик отмечает все верные суждения и получает до 2 баллов за задание.

## Возможности

- Три типа заданий (поле `type`):
  - `multiple` (по умолчанию) — выбрать все верные суждения;
  - `exclude-two` — выбрать ровно две позиции, «выпадающие» из общего ряда;
  - `matching` — установить соответствие: напротив каждой позиции А, Б, В… выбрать номер из второго столбца. Если соответствие взаимно-однозначное (`oneToOne: true`), номер нельзя использовать дважды: выбор занятого номера переносит его к новой позиции.
- Все три типа — экзаменационные форматы; «два термина, выпадающих из общего ряда» — формат задания № 1 демоверсии ФИПИ-2026.
- Оценивание — по системе оценивания части 1 демоверсии ФИПИ-2026 (см. ниже).
- После нажатия «Ответить» показываются: полученные баллы, правильный ответ, объяснение каждого суждения и кнопка «Следующее задание». До ответа правильный вариант не отображается.
- Навигация на главной странице: **раздел → тема → практикум**. Практикум — фиксированный набор заданий одной темы: «Практикум № 1», «Практикум № 2»… На карточке практикума — число заданий, максимум баллов и кнопка «Начать практикум» (или «Продолжить» / «Начать заново», если практикум не завершён). Ученик видит только темы, в которых есть опубликованный практикум; у раздела без готовых практикумов — сообщение, что они готовятся. Обобщённых пунктов («Все разделы», «Весь раздел», «Общие вопросы») нет. Подробнее — «Практикумы».
- Формат заданий ученик не выбирает: в практикум входят задания всех форматов его состава. Сохранённые в браузере раздел и тема восстанавливаются; прежние значения («все разделы», «весь раздел», поле формата) игнорируются. Фильтр по формату остаётся только в реестре (`EGE.getPool(section, topic, format)`) — для тестов и будущих режимов.
- После ответа в разборе показываются общий признак ряда (у «двух лишних терминов»), типичные ошибки и источник задания — если эти поля заданы.
- В попытку входят все задания практикума; порядок — постоянный или случайный при каждой попытке (поле `shuffle` практикума).
- Навигация по заданиям: полоса номеров показывает выполненные задания (цвет — по баллам), текущее и ещё не выполненные. К любому выполненному заданию можно вернуться и увидеть формулировку, все суждения, свой и правильный ответ, баллы и объяснения. Засчитанный ответ изменить нельзя, перейти вперёд к невыполненным — тоже.
- Итог: «N из M баллов», процент от максимума и разбор всех заданий попытки с переключателем «Все задания / Только с ошибками». Каждое задание раскрывается в полный разбор.
- Адаптивный дизайн для компьютера и смартфона, тёмная тема по настройке системы.
- Управление с клавиатуры: <kbd>1</kbd>–<kbd>9</kbd> отмечают суждения, <kbd>Enter</kbd> — ответить / дальше, <kbd>←</kbd> <kbd>→</kbd> — переход между выполненными заданиями.

## Система оценивания

> **Статус.** Правила сверены с разделом «Система оценивания экзаменационной работы» (часть 1) демонстрационного варианта КИМ ЕГЭ-2026 по обществознанию; те же правила — в п. 10 спецификации КИМ ЕГЭ-2027 (проект). Спецификация 2026 г. при сверке не использовалась. Каждое правило описано в `EGE.scoring.SCORING_RULES` (`js/scoring.js`): позиции КИМ (`kimTasks`), `verified` и ссылка на документ (`reference`). Тест `tests/formats.test.js` не допускает `verified: true` без ссылки, `tests/scoring-fipi.test.js` проверяет правила на примерах.

Для каждой модели оценивания — своя проверка (таблица `EGE.scoring.GRADERS`): свой подсчёт ошибок и своя шкала. Модель — это тип задания, а у соответствия ещё и позиция в КИМ (поле задания `kimTask`, см. ниже).

**multiple** — выбор нескольких ответов (позиции 2, 4, 5, 7, 8, 10, 11, 14, 16), максимум 2 балла.

Количество ошибок — большее из двух чисел: сколько выбрано неверных цифр и сколько верных пропущено. Так одна ошибка — это одна цифра, заменённая другой, одна лишняя или одна пропущенная («только один из символов, указанных в ответе, не соответствует эталону … или только один символ отсутствует»).

| Ошибок | Баллы |
|---|---|
| 0 (полное совпадение) | 2 |
| 1 (одна цифра заменена, одна лишняя или одна пропущена) | 1 |
| 2 и более | 0 |

Пример: правильный ответ `1, 3, 5` → `1, 3, 5` — 2 балла; `1, 4, 5` — 1 (3 заменена на 4); `1, 3` — 1; `1, 3, 5, 6` — 1; `1, 4` — 0; `1` — 0; `1, 3, 4, 6` — 0.

- **exclude-two** — два лишних термина (позиция 1), максимум 1 балл: ученик выбирает ровно две позиции, 1 балл — только если выбраны ровно обе позиции из ключа, при любой ошибке — 0. Ключ `2, 5`: `2, 5` — 1 из 1; `2`, `2, 3`, `2, 5, 6` — 0 из 1.

Соответствие оценивается по одной из двух моделей; ошибка — каждая позиция, номер которой не совпал с ключом:

- **matching** — позиции 6, 13, 15 и все соответствия без поля `kimTask`: 0 ошибок — 2 балла, 1 — 1 балл, 2 и более — 0. В заданиях `oneToOne` все номера разные, поэтому любая неточность — это перестановка минимум двух номеров, то есть 0 баллов; 1 балл возможен в соответствиях с повторяющимися номерами.
- **matching-1** — соответствие с `kimTask: 3` (позиция 3, модуль «Человек в обществе. Духовная культура»): 1 балл только при полном совпадении, иначе 0.

Поле `kimTask` необязательно и задаётся только у новых заданий; у существующих его нет, их оценивание не меняется. `npm test` проверяет, что позиция подходит типу задания. Задания 9 и 12 КИМ (выбор из списка за 1 балл) в тренажёре пока не моделируются.

## Запуск

Приложение написано на чистых HTML, CSS и JavaScript, без сборки и внешних зависимостей.

**Вариант 1 — просто открыть файл.** Дважды щёлкните `index.html`, и приложение откроется в браузере.

**Вариант 2 — локальный сервер** (удобно, чтобы открыть тренажёр с телефона в той же сети). Нужен Node.js 18+:

```bash
npm start            # http://localhost:8080
node scripts/serve.js 3000   # другой порт
```

Можно использовать любой статический сервер, например `python3 -m http.server 8080`.

**Публикация.** Папку проекта можно целиком выложить на любой статический хостинг: GitHub Pages, Netlify, Vercel и т. п.

## Сохранение и продолжение попытки

Незавершённый практикум сохраняется в браузере (`localStorage`) — модуль `js/attempt-save.js`:

- **Когда:** после старта, каждого ответа, перехода между заданиями, отметки в текущем задании, а также при закрытии вкладки и уходе со страницы (`pagehide`, `visibilitychange`).
- **Что:** порядок заданий, засчитанные ответы и баллы, задание на экране и отметки в ещё не засчитанном задании.
- **Где:** отдельная запись на каждый практикум — область «режим / раздел / тема / практикум»: `ege-trainer:attempt:ege/OBS/OBS-COG/OBS-COG-P01`. Разные практикумы друг друга не перезаписывают: можно начать «Познание», выйти, пройти часть «Деятельности» и вернуться к «Познанию» с того же места. Страница предпросмотра пишет свою запись (`…:preview/preview/poznanie-19`); настройки старта (`ege-trainer:settings`) хранятся отдельно.
- **Продолжение:** на карточке практикума — «Не завершён», «Выполнено N из M · баллы · сохранено …» и кнопки «Продолжить» / «Начать заново»; у темы — отметка «есть незавершённый». «Начать заново» и «Пройти ещё раз» начинают новую попытку вместо сохранённой; выход через шапку попытку не удаляет. Завершённая попытка удаляется из хранилища.
- **Попытки до практикумов.** Раньше запись хранилась на тему целиком (`…:ege/OBS/OBS-ACT`, `…:ege/SOC/SOC-FAM`). При открытии главной такая запись переносится в практикум или прежний набор этой темы с полем `legacyTopicAttempts` («Деятельность» — Практикум № 1, «Семья и брак» — прежний набор из 31 задания), только если полностью проходит проверку в практикуме, в том числе по составу заданий: порядок заданий, ответы, баллы и место сохраняются, прежняя запись удаляется. Остальные старые записи (`…:ege/all/all`, `…:ege/OBS/all`, темы без практикумов) не удаляются и не меняются — продолжить их в новом интерфейсе нельзя (`saver.migrate`, тесты — `tests/practicum-save.test.js`).
- **Проверка совместимости:** попытка не берётся из хранилища на веру, а проигрывается заново текущим движком. Запись отбрасывается и удаляется, а ученик видит причину, если: задание удалено, снято с выдачи или изменилось (отпечаток формулировок, ключа и `version`; правка объяснений не мешает); состав практикума изменился (для практикума с постоянным порядком — и порядок); ответ не проходит проверку; текущее оценивание даёт другие баллы или ключ; запись повреждена, от другой версии формата или старше 30 дней.
- **Две вкладки:** запись не затирает более свежее состояние той же попытки (с бо́льшим числом ответов) и чужую попытку; новая или продолженная попытка записывается явно.
- Если хранилище недоступно (приватный режим, запрет сайта), тренировка работает как раньше, без предложения продолжить.

Оценивание — по общим правилам (см. «Система оценивания»): у каждого задания набора задано поле `kimTask`, поэтому соответствия (позиция 3) оцениваются в 1 балл. Максимум за набор — 34 балла.

## Как добавить задания

Откройте файл нужной темы (например, `data/tasks/social/stratification.js`) и допишите объект в массив:

```js
EGE.addTasks('SOC-STR', [
  // ...существующие задания...
  {
    id: 'SOC-STR-002',                  // постоянный уникальный ID
    question: 'Выберите верные суждения о социальном неравенстве.',
    statements: [
      {
        text: 'Социальное неравенство — неравный доступ к ресурсам общества.',
        correct: true,
        explanation: 'Верно. ...'
      },
      {
        text: '...',
        correct: false,
        explanation: 'Неверно. ...'
      }
      // ...от 3 до 9 суждений
    ]
  }
]);
```

- Номера суждений (1, 2, 3…) присваиваются автоматически по порядку в массиве.
- Правильный ответ вычисляется из полей `correct` — отдельно хранить его не нужно.
- Тема задаётся первым аргументом `EGE.addTasks`, раздел определяется по теме.
- Поле `explanation` необязательно: если объяснения нет, после ответа у суждения показывается только его статус («Верное — вы выбрали» и т. п.).

Если в теме ещё нет файла, создайте его в папке раздела (например, `data/tasks/social/groups.js` с `EGE.addTasks('SOC-GRP', [...])`) и подключите в `index.html` рядом с остальными:

```html
<script src="data/tasks/social/groups.js"></script>
```

Когда заданий в теме станет много, файл можно разбить на несколько (`groups-2.js` и т. д.) — ID от этого не меняются. `npm test` напомнит, если файл забыли подключить.

Задание в банке ещё не видно ученику: оно выдаётся только в составе опубликованного практикума (см. «Практикумы»).

### Задания других типов

```js
{
  id: 'OBS-ACT-001',
  type: 'exclude-two',          // correct: true — позиция «выпадает» из ряда
  question: 'Ниже приведён перечень терминов. …',
  instruction: 'Найдите два термина, «выпадающих» из общего ряда.', // необязательно, под перечнем
  statements: [{ text: 'труд', correct: false, explanation: 'Не выпадает. …' }, /* … */]
},
{
  id: 'OBS-ACT-003',
  type: 'matching',
  oneToOne: true,               // каждый номер используется один раз
  question: 'Установите соответствие …',
  columns: ['Примеры', 'Виды деятельности'],
  items: [                      // позиции А, Б, В… по порядку
    { text: 'Строительство жилого дома', match: 1, explanation: '…' }
  ],
  options: ['Трудовая', 'Учебная', /* … */]   // варианты 1, 2, 3…
}
```

Формулировки адаптированы к интерфейсу: не пишите в `question`/`instruction` бланковые указания вроде «запишите цифры, под которыми они указаны» или «Ответ запишите цифрами без пробелов» — ученик выбирает ответ кнопками. Если в задании multiple выбираются не суждения, а термины или другие элементы, укажите `choiceOf: 'items'`: подсказка будет «Выберите все подходящие варианты.», а в разборе — «Подходит / Не подходит» вместо «Верное / Неверное».

Объяснения у exclude-two начинаются с «Выпадает.» / «Не выпадает.», у multiple — с «Верно.» / «Неверно.»; `npm test` проверяет, что они не противоречат ключу. В попытке ответ на matching хранится как номера по порядку позиций: `selected: [2, 4, 1, 3, 5]` означает А — 2, Б — 4 и т. д.

### Метаданные и разбор (схема 2)

Версия схемы банка — `EGE.BANK_SCHEMA_VERSION` (`js/registry.js`). Все поля схемы 2 необязательны для 36 старых заданий и проверяются тестами для новых:

```js
{
  id: 'SOC-FAM-002',
  type: 'exclude-two',
  question: '…',
  source: {                     // только если источник достоверно установлен
    kind: 'original',           // 'original' — из опубликованного пособия, 'author' — авторское
    title: 'Название пособия',  // для original обязательно
    authors: 'Фамилия И. О.',   // необязательно
    year: 2025,                 // необязательно
    ref: 'с. 22, № 3',          // место в пособии: по нему ищутся повторы
    adapted: true               // формулировка изменена под интерфейс
  },
  difficulty: 2,                // 1–3, только для внутренней классификации, ученику не показывается
  commonFeature: 'Все остальные термины — функции семьи.',  // exclude-two: общий признак ряда
  solution: 'Сначала определите…',  // необязательно: «Как решать» — общий подход, показывается в разборе
  statements: [
    { text: '…', correct: true, explanation: 'Выпадает. …', mistake: 'Типичная ошибка: …' }
  ]
}
```

- В разборе ученик видит «Источник: название, авторы, год, место» (с пометкой «формулировка адаптирована») или «Авторское задание». Без `source` источник не показывается.
- `mistake` можно указать у суждения или у позиции соответствия; в разборе — «Типичная ошибка: …».
- Новое задание (любое, кроме 36 из снимка) должно иметь `source`, содержательное объяснение каждого варианта и соответствовать формату ЕГЭ (у соответствия — 5 позиций А–Д и 2–5 вариантов во втором столбце) — см. `tests/helpers/bank-rules.js`.
- Перед добавлением задания `npm test` проверит, что оно не дублирует уже существующее.

Допишите тему в массив `topics` нужного раздела в `js/registry.js`:

## Практикумы

Реестр — `data/practicums.js` (подключается в `index.html` после всех файлов с заданиями):

```js
EGE.addPracticums([
  {
    id: 'OBS-COG-P01',          // постоянный: id темы + '-P' + номер из двух цифр
    topic: 'OBS-COG',           // все задания — из этой темы
    number: 1,                  // «Практикум № 1»; совпадает с номером в id
    status: 'published',        // 'published' — виден ученику, 'draft' — готовится, 'retired' — прежний набор
    taskIds: ['OBS-COG-031', 'OBS-COG-002', /* … */],  // состав задаётся явно
    shuffle: false,             // необязательно: true — задания в случайном порядке
    legacyTopicAttempts: false  // необязательно: см. «Сохранение и продолжение попытки»
  }
]);
```

- Состав практикума фиксирован и задаётся явно — практикумы не собираются случайной выборкой из банка. Задание входит не больше чем в один практикум.
- В теме может быть несколько самостоятельных практикумов (обычно по 12–20 заданий): «Практикум № 2» — следующая запись с `number: 2` и id `…-P02`. Пустые практикумы и практикумы «для заполнения интерфейса» не создаются.
- Практикум показывается, только если `status: 'published'` и все его задания на месте и не сняты с выдачи (`EGE.isPracticumReady`).
- Чтобы поменять состав опубликованного практикума, лучше создать следующий: незавершённая попытка прежнего состава не продолжится.
- Максимум баллов на карточке считается по системе оценивания (`EGE.getPracticumMaxScore`).

### «Научное познание»

Тема `OBS-SCK` — самостоятельная, не связанная с «Познанием» (`OBS-COG`) и с прежней скрытой темой «Наука и научное познание» (`OBS-SCI`). 50 заданий из документа преподавателя «Научное познание»: ID `OBS-SCK-001…050` совпадает с номером задания в документе (в `source.ref` — номер и код задания документа). Формулировки, порядок вариантов и ключи — как в документе; из условий убраны только указания для бланка («запишите цифры…»), поэтому `source.adapted: true`. Объяснения всех вариантов и позиций подготовлены для тренажёра.

Позиции КИМ (`kimTask`): 1 — два лишних (1 балл), 2 — выбор верных суждений (2 балла), 3 — соответствие (1 балл только за полностью верный ответ), 4 — выбор по ситуации или из списка (2 балла). Всего 5 + 19 + 17 + 9 заданий, максимум 78 баллов.

Задания распределены не по порядку документа: в каждом практикуме по 25 заданий и 39 баллов, все четыре формата (Практикум № 1 — 3/9/8/5, № 2 — 2/10/9/4), все уровни сложности и все разделы темы (наука и другие виды познания, уровни, формы знания, методы, классификация наук, функции и роль науки); одного формата подряд — не больше двух; близкие задания (32 и 33, 19 и 20, 24 и 25, 28 и 29, 30 и 43, 31 и 44, 41 и 42 и др.) — в разных практикумах. Проверяет `tests/practicums.test.js`, прохождение в браузере — `tests/e2e/browser.test.js`.

### «Общество как система. Социальные институты»

Тема `OBS-SYS` объединяет темы 1.6 и 1.7 кодификатора; прежняя тема `OBS-INS` «Социальные институты» остаётся в реестре без практикумов. 36 заданий (`OBS-SYS-001…018` — Практикум № 1, `OBS-SYS-019…036` — Практикум № 2, в порядке практикумов) перенесены без изменений из утверждённой экспертизы `proposals/OBS-SYS-EXPERTISE.md` (версия 5, включая стилистические правки С1–С13): условия, варианты, ключи, «Как решать» (`solution`), общий признак ряда, объяснения всех вариантов и типичные ошибки. В `source.ref` — код задания в экспертизе (К…, В… — авторские комплекты, `adapted: true`; Н1–Н6 — новые задания). Позиции КИМ: Практикум № 1 — 1/7/3/7 заданий позиций 1/2/3/4, 32 балла; № 2 — 2/7/3/6, 31 балл. Ключи, порядок и начисление баллов проверяет `tests/obs-sys-bank.test.js`, прохождение в браузере — `tests/e2e/browser.test.js`.

«Семья и брак» разделена на два самостоятельных практикума без повторов: каждый охватывает тему целиком (семья как институт и группа, функции, типы, брак, тенденции, социализация, роли и контроль, проблемы и поддержка семьи), в каждом все три формата и задания всех уровней сложности.

### Прежний набор (status: 'retired')

Когда состав темы меняется, прежний набор не удаляется, а получает статус `retired` и id вида `SOC-FAM-R01` (своя нумерация, обязательное поле `title`). Новым ученикам он не предлагается и заново не начинается. Карточка с его названием («Прежний набор (31 задание)») появляется над практикумами темы, только если у ученика есть сохранённая незавершённая попытка этого набора, — её можно продолжить и завершить; после завершения карточка исчезает, кнопки «Пройти ещё раз» на итогах нет. Сохранения удаляются только по общим правилам (завершение, несовместимость, срок 30 дней). Задания прежнего набора могут совпадать с заданиями действующих практикумов; между действующими практикумами задания не повторяются.

`SOC-FAM-R01` — все 31 задание «Семьи и брака», как тема выдавалась до разделения; в него переносятся попытки, сохранённые для темы целиком (`ege/SOC/SOC-FAM`).

Остальные темы скрыты до появления в них практикумов; разделы «Экономика», «Политика» и «Право» показывают сообщение, что практикумы готовятся.

## Подготовка к базе данных

Попытка (`js/attempt.js`) — простой JSON-объект без ссылок на объекты заданий:

```js
{
  schemaVersion: 1,
  id: 'uuid',
  startedAt: '2026-09-23T10:00:00.000Z', finishedAt: null,
  settings: { section: 'SOC', topic: 'all' },
  taskIds: ['SOC-MOB-001', 'SOC-STR-001', ...],   // порядок показа
  answers: [{
    taskId: 'SOC-MOB-001', taskVersion: 1, position: 1,
    selected: [1, 3], correct: [1, 3, 5],
    points: 1, maxPoints: 2, answeredAt: '...'
  }]
}
```

Для отправки на сервер предусмотрены точки расширения — сейчас они ничего не делают:

```js
EGE.attemptStore = {
  onAnswer: function (answer, attempt) { /* сразу после засчитанного ответа */ },
  onFinish: function (attempt) { /* один раз при завершении попытки */ }
};
```

Их можно переопределить в отдельном файле, подключённом после `js/attempt.js`. Приложение передаёт в них независимые копии данных, а ошибка внутри них не прерывает тренировку. Сервер должен сам пересчитывать баллы по `selected` — значению `points` с клиента доверять нельзя.
