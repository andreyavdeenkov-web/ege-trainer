# ЕГЭ Обществознание — тренажёр

Веб-приложение для подготовки к ЕГЭ по обществознанию. Первая версия — тренажёр заданий с множественным выбором: ученик отмечает все верные суждения и получает до 2 баллов за задание.

## Возможности

- Три типа заданий (поле `type`):
  - `multiple` (по умолчанию) — выбрать все верные суждения;
  - `exclude-two` — выбрать ровно две позиции, «выпадающие» из общего ряда;
  - `matching` — установить соответствие: напротив каждой позиции А, Б, В… выбрать номер из второго столбца. Если соответствие взаимно-однозначное (`oneToOne: true`), номер нельзя использовать дважды: выбор занятого номера переносит его к новой позиции.
- Все три типа — экзаменационные форматы; «два термина, выпадающих из общего ряда» — формат задания № 1 демоверсии ФИПИ-2026.
- Оценивание по рабочим правилам тренажёра (см. ниже); сверка с официальной спецификацией ФИПИ-2026 ещё не выполнена.
- После нажатия «Ответить» показываются: полученные баллы, правильный ответ, объяснение каждого суждения и кнопка «Следующее задание». До ответа правильный вариант не отображается.
- Банк заданий устроен в два уровня: **раздел → тема → задания**. На старте можно выбрать все разделы, один раздел целиком или одну тему. Темы, в которых пока нет заданий, не показываются.
- Фильтр **«Формат»**: все типы заданий, выбор нескольких ответов, два лишних термина, установление соответствия. Счётчики разделов и тем показывают задания выбранного формата; формат, которого нет в выбранных разделе и теме, недоступен. Раздел, тема и формат запоминаются в браузере.
- После ответа в разборе показываются общий признак ряда (у «двух лишних терминов»), типичные ошибки и источник задания — если эти поля заданы.
- В тренировку входят все задания выбранной темы, раздела или всего банка; задания перемешиваются при каждой попытке.
- Навигация по заданиям: полоса номеров показывает выполненные задания (цвет — по баллам), текущее и ещё не выполненные. К любому выполненному заданию можно вернуться и увидеть формулировку, все суждения, свой и правильный ответ, баллы и объяснения. Засчитанный ответ изменить нельзя, перейти вперёд к невыполненным — тоже.
- Итог: «N из M баллов», процент от максимума и разбор всех заданий попытки с переключателем «Все задания / Только с ошибками». Каждое задание раскрывается в полный разбор.
- Адаптивный дизайн для компьютера и смартфона, тёмная тема по настройке системы.
- Управление с клавиатуры: <kbd>1</kbd>–<kbd>9</kbd> отмечают суждения, <kbd>Enter</kbd> — ответить / дальше, <kbd>←</kbd> <kbd>→</kbd> — переход между выполненными заданиями.

## Система оценивания

> **Статус.** Ниже — рабочие правила тренажёра. Они **ещё не сверены** с официальной спецификацией и демоверсией ФИПИ-2026 и не должны считаться официальными критериями. Каждое правило описано в `EGE.scoring.SCORING_RULES` (`js/scoring.js`) с полем `verified: false`; после сверки там появятся `verified: true` и ссылка на документ (`reference`). Тест `tests/formats.test.js` не допускает `verified: true` без ссылки.

Для каждого типа — своя проверка (таблица `EGE.scoring.GRADERS`): свой подсчёт ошибок и своя шкала. Оценивание multiple и matching не смешивается: шкала у них одинаковая, а ошибки считаются по-разному.

**multiple** — выбор нескольких ответов.

Количество ошибок — размер симметрической разности множества выбранных вариантов и множества правильных:

| Ошибок | Баллы |
|---|---|
| 0 (полное совпадение) | 2 |
| 1 (пропущен один верный или выбран один лишний) | 1 |
| 2 и более | 0 |

Пример: правильный ответ `1, 3, 5` → `1, 3, 5` — 2 балла; `1, 3` — 1; `1, 3, 5, 6` — 1; `1, 4, 5` — 0; `1` — 0.

- **exclude-two** — два лишних термина (формат задания № 1), максимум 1 балл: ученик выбирает ровно две позиции, 1 балл — только если выбраны ровно обе позиции из ключа, при любой ошибке — 0. Ключ `2, 5`: `2, 5` — 1 из 1; `2`, `2, 3`, `2, 5, 6` — 0 из 1.

Для matching шкала та же, что у multiple (0 ошибок — 2, 1 — 1, 2 и более — 0), меняется только подсчёт ошибок:

- **matching** — ошибка — каждая позиция, номер которой не совпал с ключом. В заданиях `oneToOne` все номера разные, поэтому любая неточность — это перестановка минимум двух номеров, то есть не меньше двух ошибок (0 баллов); 1 балл возможен в соответствиях с повторяющимися номерами.

## Запуск

Приложение написано на чистых HTML, CSS и JavaScript, без сборки и внешних зависимостей.

**Вариант 1 — просто открыть файл.** Дважды щёлкните `index.html`, и приложение откроется в браузере.

**Вариант 2 — локальный сервер** (удобно, чтобы открыть тренажёр с телефона в той же сети). Нужен Node.js 18+:

```bash
npm start            # http://localhost:8080
node scripts/serve.js 3000   # другой порт
```

Можно использовать любой статический сервер, например `python3 -m http.server 8080`.

**Публикация.** Папку проекта можно целиком выложить на любой статический хостинг: GitHub Pages, Netlify, Vercel и т. п.

- фильтр формата и оценивание по форматам (`tests/formats.test.js`): пул по формату, смешанная попытка, частичные ответы, повторное прохождение, статус сверки правил;

## Разделы, темы и ID заданий

Разделы и темы описаны в `EGE.sections` (`js/registry.js`):

| Раздел | id | Темы |
|---|---|---|
| Человек и общество | `OBS` | `OBS-GEN` Общие вопросы, `OBS-ACT` Деятельность |
| Экономика | `ECO` | `ECO-GEN` Общие вопросы |
| Социальные отношения | `SOC` | `SOC-STR` стратификация, `SOC-MOB` мобильность, `SOC-GRP` группы, `SOC-YTH` молодёжь, `SOC-ETH` этнические общности, `SOC-CNF` конфликт, `SOC-CTL` контроль, `SOC-FAM` семья и брак |
| Политика | `POL` | `POL-GEN` Общие вопросы |
| Право | `LAW` | `LAW-GEN` Общие вопросы |

Каждое задание имеет **постоянный ID** вида `SOC-STR-001` (раздел-тема-номер). ID задаётся вручную в данных и не зависит от порядка заданий в файле или порядка показа. Правила:

- ID никогда не меняется и не используется повторно — даже если задание удалено. Вместо удаления ставьте `retired: true`: задание перестанет выдаваться, а ID останется занятым.
- Не переставляйте и не вставляйте суждения в уже опубликованном задании: сохранённые ответы ссылаются на номера суждений. Если правка всё же нужна, увеличьте `version` (по умолчанию 1) — номер версии записывается в каждый ответ.

## Как добавить задания

Откройте файл нужной темы (например, `data/tasks/social/stratification.js`) и допишите объект в массив:

```js
EGE.addTasks('SOC-STR', [
  // ...существующие задания...
  {
    id: 'SOC-STR-002',                  // постоянный уникальный ID
    question: 'Выберите верные суждения о социальном неравенстве.',
    statements: [
      {
        text: 'Социальное неравенство — неравный доступ к ресурсам общества.',
        correct: true,
        explanation: 'Верно. ...'
      },
      {
        text: '...',
        correct: false,
        explanation: 'Неверно. ...'
      }
      // ...от 3 до 9 суждений
    ]
  }
]);
```

- Номера суждений (1, 2, 3…) присваиваются автоматически по порядку в массиве.
- Правильный ответ вычисляется из полей `correct` — отдельно хранить его не нужно.
- Тема задаётся первым аргументом `EGE.addTasks`, раздел определяется по теме.
- Поле `explanation` необязательно: если объяснения нет, после ответа у суждения показывается только его статус («Верное — вы выбрали» и т. п.).

Если в теме ещё нет файла, создайте его в папке раздела (например, `data/tasks/social/groups.js` с `EGE.addTasks('SOC-GRP', [...])`) и подключите в `index.html` рядом с остальными:

```html
<script src="data/tasks/social/groups.js"></script>
```

Когда заданий в теме станет много, файл можно разбить на несколько (`groups-2.js` и т. д.) — ID от этого не меняются. `npm test` напомнит, если файл забыли подключить.

### Задания других типов

```js
{
  id: 'OBS-ACT-001',
  type: 'exclude-two',          // correct: true — позиция «выпадает» из ряда
  question: 'Ниже приведён перечень терминов. …',
  instruction: 'Найдите два термина, «выпадающих» из общего ряда.', // необязательно, под перечнем
  statements: [{ text: 'труд', correct: false, explanation: 'Не выпадает. …' }, /* … */]
},
{
  id: 'OBS-ACT-003',
  type: 'matching',
  oneToOne: true,               // каждый номер используется один раз
  question: 'Установите соответствие …',
  columns: ['Примеры', 'Виды деятельности'],
  items: [                      // позиции А, Б, В… по порядку
    { text: 'Строительство жилого дома', match: 1, explanation: '…' }
  ],
  options: ['Трудовая', 'Учебная', /* … */]   // варианты 1, 2, 3…
}
```

Формулировки адаптированы к интерфейсу: не пишите в `question`/`instruction` бланковые указания вроде «запишите цифры, под которыми они указаны» или «Ответ запишите цифрами без пробелов» — ученик выбирает ответ кнопками. Если в задании multiple выбираются не суждения, а термины или другие элементы, укажите `choiceOf: 'items'`: подсказка будет «Выберите все подходящие варианты.», а в разборе — «Подходит / Не подходит» вместо «Верное / Неверное».

Объяснения у exclude-two начинаются с «Выпадает.» / «Не выпадает.», у multiple — с «Верно.» / «Неверно.»; `npm test` проверяет, что они не противоречат ключу. В попытке ответ на matching хранится как номера по порядку позиций: `selected: [2, 4, 1, 3, 5]` означает А — 2, Б — 4 и т. д.

### Метаданные и разбор (схема 2)

Версия схемы банка — `EGE.BANK_SCHEMA_VERSION` (`js/registry.js`). Все поля схемы 2 необязательны для 36 старых заданий и проверяются тестами для новых:

```js
{
  id: 'SOC-FAM-002',
  type: 'exclude-two',
  question: '…',
  source: {                     // только если источник достоверно установлен
    kind: 'original',           // 'original' — из опубликованного пособия, 'author' — авторское
    title: 'Название пособия',  // для original обязательно
    authors: 'Фамилия И. О.',   // необязательно
    year: 2025,                 // необязательно
    ref: 'с. 22, № 3',          // место в пособии: по нему ищутся повторы
    adapted: true               // формулировка изменена под интерфейс
  },
  difficulty: 2,                // 1–3, только для внутренней классификации, ученику не показывается
  commonFeature: 'Все остальные термины — функции семьи.',  // exclude-two: общий признак ряда
  statements: [
    { text: '…', correct: true, explanation: 'Выпадает. …', mistake: 'Типичная ошибка: …' }
  ]
}
```

- В разборе ученик видит «Источник: название, авторы, год, место» (с пометкой «формулировка адаптирована») или «Авторское задание». Без `source` источник не показывается.
- `mistake` можно указать у суждения или у позиции соответствия; в разборе — «Типичная ошибка: …».
- Новое задание (любое, кроме 36 из снимка) должно иметь `source`, содержательное объяснение каждого варианта и соответствовать формату ЕГЭ (у соответствия — 5 позиций А–Д и 2–5 вариантов во втором столбце) — см. `tests/helpers/bank-rules.js`.
- Перед добавлением задания `npm test` проверит, что оно не дублирует уже существующее.

### Как добавить тему

Допишите тему в массив `topics` нужного раздела в `js/registry.js`:

```js
{ id: 'ECO-MON', title: 'Деньги' }
```

id темы — код раздела и три латинские буквы. Пока в теме нет заданий, ученик её не видит. Когда у раздела появятся настоящие темы, задания из «Общих вопросов» можно перенести в них, оставив прежние ID.

## Подготовка к базе данных

Попытка (`js/attempt.js`) — простой JSON-объект без ссылок на объекты заданий:

```js
{
  schemaVersion: 1,
  id: 'uuid',
  startedAt: '2026-09-23T10:00:00.000Z', finishedAt: null,
  settings: { section: 'SOC', topic: 'all' },
  taskIds: ['SOC-MOB-001', 'SOC-STR-001', ...],   // порядок показа
  answers: [{
    taskId: 'SOC-MOB-001', taskVersion: 1, position: 1,
    selected: [1, 3], correct: [1, 3, 5],
    points: 1, maxPoints: 2, answeredAt: '...'
  }]
}
```

Для отправки на сервер предусмотрены точки расширения — сейчас они ничего не делают:

```js
EGE.attemptStore = {
  onAnswer: function (answer, attempt) { /* сразу после засчитанного ответа */ },
  onFinish: function (attempt) { /* один раз при завершении попытки */ }
};
```

Их можно переопределить в отдельном файле, подключённом после `js/attempt.js`. Приложение передаёт в них независимые копии данных, а ошибка внутри них не прерывает тренировку. Сервер должен сам пересчитывать баллы по `selected` — значению `points` с клиента доверять нельзя.
