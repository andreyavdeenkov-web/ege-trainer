# ЕГЭ Обществознание — тренажёр

Веб-приложение для подготовки к ЕГЭ по обществознанию. Первая версия — тренажёр заданий с множественным выбором: ученик отмечает все верные суждения и получает до 2 баллов за задание.

## Возможности

- Задания с пронумерованными суждениями: нужно выбрать все верные.
- Оценивание по правилам ЕГЭ (см. ниже).
- После нажатия «Ответить» показываются: полученные баллы, правильный ответ, объяснение каждого суждения и кнопка «Следующее задание». До ответа правильный вариант не отображается.
- Прогресс «Задание 2 из 5» и текущая сумма баллов.
- Итог: «N из M баллов», процент от максимума, список заданий с ошибками и кнопка «Пройти ещё раз».
- Выбор темы («Человек и общество», «Экономика», «Социальные отношения», «Политика», «Право» или все сразу) и количества заданий (5, 10, все). Задания перемешиваются при каждой попытке.
- Адаптивный дизайн для компьютера и смартфона, тёмная тема по настройке системы.
- Управление с клавиатуры: <kbd>1</kbd>–<kbd>9</kbd> отмечают суждения, <kbd>Enter</kbd> — ответить / дальше.

## Система оценивания

Количество ошибок — размер симметрической разности множества выбранных вариантов и множества правильных:

| Ошибок | Баллы |
|---|---|
| 0 (полное совпадение) | 2 |
| 1 (пропущен один верный или выбран один лишний) | 1 |
| 2 и более | 0 |

Пример: правильный ответ `1, 3, 5` → `1, 3, 5` — 2 балла; `1, 3` — 1; `1, 3, 5, 6` — 1; `1, 4, 5` — 0; `1` — 0.

## Запуск

Приложение написано на чистых HTML, CSS и JavaScript, без сборки и внешних зависимостей.

**Вариант 1 — просто открыть файл.** Дважды щёлкните `index.html`, и приложение откроется в браузере.

**Вариант 2 — локальный сервер** (удобно, чтобы открыть тренажёр с телефона в той же сети). Нужен Node.js 18+:

```bash
npm start            # http://localhost:8080
node scripts/serve.js 3000   # другой порт
```

Можно использовать любой статический сервер, например `python3 -m http.server 8080`.

**Публикация.** Папку проекта можно целиком выложить на любой статический хостинг: GitHub Pages, Netlify, Vercel и т. п.

## Тесты

```bash
npm test
```

Тесты проверяют:
- логику оценивания (`tests/scoring.test.js`), включая все примеры из условия;
- банк заданий (`tests/tasks.test.js`): у каждого задания есть тема, вопрос, от 3 до 9 суждений с объяснениями, хотя бы одно верное и одно неверное суждение, id уникальны, а все файлы из `data/tasks/` подключены в `index.html`.

## Структура проекта

```
index.html              разметка трёх экранов: старт, задание, итоги
css/styles.css          стили (светлая и тёмная темы, адаптивная вёрстка)
js/registry.js          список тем и реестр заданий (EGE.addTasks)
js/scoring.js           чистые функции оценивания (работают и в Node.js)
js/app.js               логика интерфейса
data/tasks/             банк заданий — по одному файлу на тему
  society.js            Человек и общество
  economy.js            Экономика
  social.js             Социальные отношения
  politics.js           Политика
  law.js                Право
scripts/serve.js        простой локальный сервер без зависимостей
tests/                  автотесты (node --test)
```

## Как добавить задания

Откройте файл нужной темы в `data/tasks/` и допишите объект в массив:

```js
EGE.addTasks('economy', [
  // ...существующие задания...
  {
    id: 'economy-004',                 // уникальный id
    question: 'Выберите верные суждения о деньгах.',
    statements: [
      {
        text: 'Деньги выполняют функцию меры стоимости.',
        correct: true,
        explanation: 'Верно. С помощью денег измеряется стоимость всех товаров и услуг.'
      },
      {
        text: 'Бартер — обмен товарами с использованием денег.',
        correct: false,
        explanation: 'Неверно. Бартер — прямой обмен товара на товар без денег.'
      }
      // ...от 3 до 9 суждений
    ]
  }
]);
```

- Номера суждений (1, 2, 3…) присваиваются автоматически по порядку в массиве.
- Правильный ответ вычисляется из полей `correct` — отдельно хранить его не нужно.
- Тема задаётся первым аргументом `EGE.addTasks` — указывать её в самом задании не надо.

Когда заданий станет много, файл темы можно разбить на несколько (например, `data/tasks/economy-money.js`, `data/tasks/economy-taxes.js`). Каждый новый файл подключите в `index.html` рядом с остальными:

```html
<script src="data/tasks/economy-money.js"></script>
```

`npm test` напомнит, если файл забыли подключить.

### Как добавить тему

Добавьте запись в массив `EGE.topics` в `js/registry.js`:

```js
{ id: 'history', title: 'Новая тема', color: '#8b5cf6' }
```

После этого тема появится на стартовом экране, и в неё можно добавлять задания через `EGE.addTasks('history', [...])`.
